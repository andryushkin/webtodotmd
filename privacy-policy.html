to .md — Privacy Policy

Effective date: 2026-03-16  ·  Last updated: 2026-07-24

Short version: to .md converts everything locally in your browser. Your selections, the Markdown they produce, and the pages you visit never leave your device. The only thing sent anywhere is an anonymous counter of how often features are used — no accounts, no profiles, no page data.

1. What to .md Does

to .md is a Chrome browser extension that converts selected text on web pages into clean, formatted Markdown. You select text, click a button (or use a keyboard shortcut), and the Markdown is placed in your clipboard or shown in the side panel.

2. Data We Do Not Collect

to .md does not collect, store, transmit, or share any of the following:

  • The text you select on any web page
  • The Markdown content generated by the extension
  • URLs or titles of pages you visit
  • Your browsing history
  • Personal information of any kind
  • Anything that could identify you or link usage back to a person

3. Anonymous Usage Counters

To know which features are worth maintaining, the extension sends a small event to https://2md.site/api/event when you copy, download, hand a note to another app, or rate the extension. Each event contains exactly four fields:

  • Install ID — a random UUID generated on your device at install time. It is not derived from anything about you or your browser, and it is not linked to any other identifier.
  • Event name — for example copy, download_md or rating_5.
  • Interface language and extension version.

No page content, URL, title, or timestamp of what you captured is included. The request is fire-and-forget: if it fails, the extension ignores the failure and carries on. The receiving endpoint is operated by the extension's developer, not by an advertising or analytics company.

4. Local Storage

The extension uses chrome.storage.local and chrome.storage.session to store the following data locally on your device only:

  • Settings — your preferences: interface language, highlight colour, default view mode, whether metadata and the floating button are enabled.
  • Install ID — the anonymous UUID described in section 3, kept so the same random value is reused instead of generating a new one each time.
  • Action counter — how many times you have copied or downloaded, used only to decide when to show the rating prompt once, and when to stop showing it.
  • Capture signal — a session-only timestamp used to coordinate between the toolbar icon click and the side panel. Cleared when the browser session ends.

Apart from the four fields listed in section 3, none of this is transmitted anywhere.

5. Permissions Explained

The extension requests the following browser permissions:

  • activeTab — to read the selected text on the currently active page when you explicitly trigger a capture. Access is granted only for the moment of the action.
  • sidePanel — to display the Markdown preview in Chrome's side panel.
  • storage — to store your settings, the action counter and the install ID locally.
  • contextMenus — to add a "Copy as Markdown" item to the right-click menu.
  • clipboardWrite — to write the converted Markdown to your clipboard.
  • downloads — to save the Markdown as a .md file when you click the Download button.
  • tabs — to identify the active tab when capturing from the side panel.

No permission is used for any purpose other than what is described above.

6. Third-Party Services

to .md does not communicate with any third-party servers, APIs, or analytics services. The counters in section 3 go to 2md.site, which is run by the extension's developer. All HTML-to-Markdown conversion happens entirely in your browser using bundled libraries (htmltodotmd, marked, DOMPurify, KaTeX), which are compiled into the extension and load nothing from the network.

7. Content Security

The extension uses DOMPurify to sanitize all rendered HTML output, preventing XSS attacks. No content from web pages is ever injected into the extension's UI in an unsafe way.

8. Children's Privacy

to .md does not knowingly collect any information from anyone, including children under the age of 13. The extension collects no personal data whatsoever.

9. Changes to This Policy

If this Privacy Policy changes materially, the updated version will be published at this URL with a new effective date. Continued use of the extension after changes constitutes acceptance of the updated policy.
