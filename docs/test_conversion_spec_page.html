Conversion specification test page

A manual fixture for Text to .md. Serve this file over HTTP, reload the unpacked extension, and select only the white subject area of one case. Compare the page, Preview, and Source/downloaded Markdown.

Blocks Inline CSS Lists and code Tables Links and media Escaping Removal Math Real-world Modes Known limits

Run from the repository root: python3 -m http.server 8000, then open http://localhost:8000/docs/test_conversion_spec_page.html. The extension cannot run on file:// pages.

Each gray strip describes the assertion and is outside the subject. The extension raises the shallowest heading of a capture to ## and moves the rest by the same amount, never pushing one deeper — so what a heading becomes depends on what else the selection caught: take B5 alone and its aria-level="3" is ##, while B1 keeps its h1 as #, the rank the page itself gave it. The base carries across presses of the button, so capturing this page in several goes keeps the ranks apart. Cases marked “setting” require the named option. Known limitations are collected at the end.
