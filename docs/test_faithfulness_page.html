Faithfulness test page

Companion to store/research/manual-test-checklist.md. Every section is one case: Do says what to select, Want says what should come out. The bordered box is the thing to select.

Serve it over HTTP — the extension cannot run on file:// pages. From the repo root: python3 -m http.server 8000, then open http://localhost:8000/docs/test_faithfulness_page.html.

Check three things every time, not one: what this page shows, what the Preview shows, and what is in Source / the downloaded .md. Preview and file agreeing is half the point.
