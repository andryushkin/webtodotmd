For the redraw

  • Canvas 1280 × 800, PNG 24-bit, no alpha — the store rejects transparency. Margins here: 64 px sides, 54 top, 48 bottom.
  • Type sizes as drawn: headline 62, standfirst 21, number 54, tile line 19, tile note 15, footer 18. Headline face is a geometric sans matching the burnt-in captions of slides 1–4; this file only approximates it.
  • Accents are the two already in use: #a9d3f0 and #d9b8f5, alternating tile by tile. Field #2f2f2f, cards #3a3a3a.
  • Icons are placeholders drawn as strokes — swap for the set you prefer, keep them 40 px and single-weight.

Where each number comes from (all re-derivable)

  • 0 hidden text — the spec page hides 18 payloads (display:none, opacity:0, clip-path, off-screen, sr-only, collapsed <details>, <iframe srcdoc> …); none appear in our clip.
  • 52 languages — public/_locales/.
  • 90 cases — labelled cases in docs/test_conversion_spec_page.html, in the public repository.
  • 1855 tests — bun test, extension and core together.
  • 4 ways out — .md, .txt, Obsidian, EditMD (plus copy).
  • 4× more checks — store/research/compare-clippers.ts scores two clips of the same page against 21 published yes/no checks: 21/21 against 5/21. The list was written from the page's cases, not from either file's behaviour, and it ships so anyone can re-run it. Eighteen ways of hiding text count as one check, not eighteen, or half the score would rest on a single question.

Say this next to the 4×

  • One page, ours, both sides clipping everything with ⌘A. It is a fair test only in that both met the same document — it is not a survey of the web.
  • The other clipper is built around Readability: it takes the article it detects rather than what you selected. Several misses follow from that difference in promise, not from a bug.

Deliberately absent

  • No competitor named: “the nearest clipper” is as far as one page we wrote ourselves can carry a claim on a storefront. If you name it, expect to defend the list of checks — which is why the list is published.
  • Nothing about telemetry as a selling point. Conversion is local, but anonymous counters (event name, locale, version) do leave, so any privacy line must say “page content”, never “zero network”.
  • No claim of whole-page capture — nothing here should read as one-click clipping of a page you did not select.
