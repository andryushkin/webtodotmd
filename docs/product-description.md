# to .md — описание продукта

> Фактическое описание функций и возможностей расширения.
> Предназначено как исходник для копирайтеров — без маркетинговых формулировок.

## Что это

Chrome-расширение, которое конвертирует выделенный текст на веб-страницах в чистый Markdown. Результат можно скопировать в буфер обмена, отредактировать или скачать как `.md`-файл.

Работает через боковую панель Chrome (Side Panel). Не требует аккаунта, не отправляет данные на сервер — всё происходит локально в браузере.

## Три способа захвата

### 1. Выделение текста

Выделить текст на странице → нажать кнопку «Capture» в боковой панели. Расширение конвертирует HTML в Markdown с сохранением форматирования: заголовки, списки, таблицы, блоки кода, ссылки, изображения.

Если выделить несколько фрагментов (Cmd/Ctrl + клик), они объединяются через разделитель.

### 2. Режим Highlighter

Альтернативный способ — поэлементный выбор. Включается кнопкой в панели. После включения:

- при наведении на элемент (абзац, заголовок, список, таблицу, блок кода, цитату) появляется пунктирная рамка;
- клик фиксирует элемент — он подсвечивается цветом;
- можно выбрать несколько элементов в произвольном порядке;
- повторный клик снимает выделение с элемента.

Кнопка «Capture» собирает все подсвеченные элементы в один Markdown-документ в порядке их расположения на странице. После захвата подсветка автоматически снимается.

Highlighter автоматически отключается при переключении на другую вкладку или закрытии панели.

### 3. Горячая клавиша Alt+M

Конвертирует выделенный текст в Markdown и сразу копирует в буфер обмена. Работает без открытия панели — результат подтверждается toast-уведомлением.

## Всплывающая кнопка (Floating Bubble)

При выделении текста на странице рядом с курсором появляется кнопка «add to .md». Клик по ней открывает боковую панель и автоматически захватывает выделение. Можно отключить в настройках.

## Контекстное меню

Правый клик на странице → «add to .md» — открывает панель и захватывает выделенный текст.

## Боковая панель (Side Panel)

### Просмотр результата

Два режима просмотра, переключаются кнопками:

- **Preview** — отрендеренный Markdown (заголовки, таблицы, код с подсветкой, формулы);
- **Source** — сырой Markdown в редактируемом текстовом поле.

### Редактирование

В режиме Source текст можно редактировать вручную. Поддерживается undo/redo (до 50 шагов). Изменения сразу отражаются в Preview.

### Кнопки действий

| Кнопка | Действие |
|--------|----------|
| Copy | Копирует сырой Markdown в буфер обмена |
| Download | Скачивает `.md`-файл (имя генерируется из заголовка страницы) |
| Clear | Очищает содержимое и сбрасывает историю |
| Undo / Redo | Отмена/повтор последнего изменения |

### Строка статуса

Показывает текущее состояние: готовность к захвату, ошибки (нет выделения, страница недоступна, таймаут), подтверждение успешного захвата. На ограниченных страницах (PDF, chrome://, пустая вкладка) — предупреждение с пояснением.

### Счётчик захватов

В подвале панели: «Copied today: N» — количество операций копирования/скачивания за сутки. Сбрасывается ежедневно.

## Накопительный захват

Несколько последовательных захватов с одной страницы объединяются в один документ. При захвате с другой страницы (и включённых метаданных) добавляется новый блок метаданных. Без метаданных — визуальный разделитель `---`.

## Метаданные

При включённой настройке «Auto-add metadata» к каждому захвату добавляется YAML-блок:

```
title: Заголовок страницы
source: https://example.com/page
date: 2026-03-19T12:00:00Z
```

Заголовок извлекается из Open Graph, Twitter Card, Schema.org JSON-LD или HTML `<title>` (в порядке приоритета).

## Поддержка форматирования

- Заголовки H1–H6
- Жирный, курсив
- Нумерованные и маркированные списки (вложенные)
- Таблицы
- Блоки кода (с указанием языка)
- Инлайн-код
- Ссылки (с полным URL)
- Изображения
- Цитаты (blockquote)
- Горизонтальные линии
- Подстрочный (`<sub>`) и надстрочный (`<sup>`) текст

### Математические формулы

Инлайн-формулы `$...$` и блочные `$$...$$` рендерятся через KaTeX. MathML-выражения автоматически конвертируются в LaTeX. Если рендеринг невозможен — отображается исходный LaTeX-код.

### Shadow DOM

Контент внутри Shadow DOM (веб-компоненты, кастомные элементы) извлекается и включается в захват.

## Настройки

Открываются через иконку шестерёнки в панели.

| Настройка | Тип | По умолчанию | Описание |
|-----------|-----|-------------|----------|
| Auto-add metadata | Переключатель | Включено | Добавлять блок метаданных к каждому захвату |
| Show floating bubble | Переключатель | Включено | Показывать кнопку «add to .md» при выделении текста |
| Default view mode | Выбор: Preview / Source | Preview | Режим просмотра при открытии панели |
| Highlight color | Палитра цветов | #0066cc | Цвет подсветки элементов в режиме Highlighter |
| Language | Выбор из 20 языков | Auto (язык браузера) | Язык интерфейса расширения |

Настройки сохраняются автоматически и применяются мгновенно ко всем компонентам расширения.

## Языки интерфейса

20 языков: English, Deutsch, Français, Español, Italiano, Nederlands, Svenska, Dansk, Norsk, Suomi, العربية (RTL), Bahasa Indonesia, Русский, Português (PT), 日本語, Filipino, Tiếng Việt, Türkçe, ภาษาไทย, 한국어.

Выбирается в настройках. По умолчанию — язык браузера.

## Где работает, а где нет

**Работает:** любые HTTP/HTTPS-страницы.

**Не работает:**
- PDF-файлы
- Локальные файлы (`file://`)
- Служебные страницы Chrome (`chrome://`, `about:`, `chrome-extension://`)
- Страницы других расширений

На недоступных страницах кнопка захвата неактивна, в статусной строке — пояснение.

## Приватность и безопасность

- Данные не покидают браузер — нет серверной части, нет аналитики
- Контент-скрипт загружается только при захвате (не на каждой странице)
- XSS-защита через DOMPurify при рендеринге превью
- HTML-теги в пользовательском контенте экранируются

## Технические характеристики

- Manifest V3
- Версия: 1.0.0
- Размер: ~200 KB (без внешних зависимостей в рантайме)
- Движок конвертации: @markitdown/core
- Рендер Markdown: marked + DOMPurify
- Рендер формул: KaTeX
- Иконки: Lucide (inline SVG)
