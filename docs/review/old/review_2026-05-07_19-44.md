### src/content/content-script.ts

#### Security & Permissions
- **Message origin validation missing** (medium)  
  `chrome.runtime.onMessage` listener does not verify `_sender.id` before processing messages. If the extension allows `externally_connectable` or another extension can reach this context, malicious messages could be accepted.  
  *Recommendation:* Add `if (_sender.id !== chrome.runtime.id) return;` at the top of the listener.  

- **Missing permission check for `navigator.clipboard.writeText`** (low)  
  The CAPTURE_AND_COPY handler calls `navigator.clipboard.writeText()`. This requires the `clipboardWrite` permission in manifest V3. If the permission is absent, the promise will reject silently, potentially confusing the user. The extension should check for the API or handle errors gracefully.

#### Content Script Isolation
No issues detected. Shadow DOM handling uses explicit cleanup, bubble and highlighter are namespaced, and all identifiers are limited to the content script’s isolated world.

#### Message Passing
- **No origin check** (medium – same as above)  
- **Race condition in bubble click handling** (low)  
  `bubbleClicked` is reset after a 400 ms timeout, but if another `selectionchange` fires before that, the bubble may not hide correctly. However, impact is minimal because `mouseDownHiding` suppresses spurious shows.

- **Missing response for OPEN_AND_CAPTURE** (low)  
  `chrome.runtime.sendMessage` fires `OPEN_AND_CAPTURE` without waiting for a response; this is intentional, but if the background script expects an answer it could cause warnings.

#### TypeScript Quality
- **Implicit `any` in message listener** (low)  
  The `msg` parameter is not typed, relying on `satisfies` inside the block. A proper union type would improve maintainability.  
- **`textNodes` cast to `Text[]`** (low)  
  The tree walker returns `Node`, casting each to `Text` is safe but could be more explicitly checked.

#### Storage API
No issues. Uses `chrome.storage.local` and `onChanged` correctly.

#### Performance
- **Long‑lived event listeners** (low)  
  `selectionchange`, `mousedown`, `mouseup` listeners are always active. On pages with frequent selection changes (e.g., rich editors), it may cause minor overhead. Acceptable for typical usage.

### src/sidepanel/sidepanel.ts

#### Security & Permissions
- **XSS prevention** (low)  
  The pipeline `escapeHtmlTagsInMarkdown → marked (html: true) → DOMPurify.sanitize` is robust. `DOMPurify` is imported and applied before `innerHTML`. No direct injection possible.  
- **Missing origin check in sidepanel message listener** (low)  
  `chrome.runtime.onMessage` for `HIGHLIGHT_COUNT` does not validate sender. Could theoretically be spoofed, but side panel usually only talks to the extension’s own contexts.

#### Message Passing
- **No origin validation** (low) – as above.
- **`sendMessageWithTimeout` does not retry on disconnection** (low)  
  If the content script context is destroyed between `ensureContentScript` and `sendMessage`, the 3‑second timeout catches it, but a more graceful recovery could be implemented.

#### TypeScript Quality
- **Missing null checks for DOM elements** (medium)  
  Multiple `getElementById` results are cast directly (`as HTMLButtonElement`) without checking for `null`. If the HTML template changes, these will throw at runtime.  
  *Affected references:* `btnCapture`, `btnHighlighter`, `btnUndo`, … – all toolbar buttons and the status/rating containers.

- **Unused variable `tabRestricted`** (low)  
  `tabRestricted` is set but never read; it may be leftover from earlier logic.

#### Storage API
- **Non‑atomic action counter** (low)  
  `incrementActionCount` reads `actionCount`, increments, and writes it back. A rapid double‑click could lose an increment, but given the user interaction it is unlikely to cause issues.

#### Performance
- **`preprocessMath` regex complexity** (low)  
  The function uses multiline regexes on arbitrary Markdown; while acceptable for typical capture sizes, extremely large content may cause a momentary freeze. Caching or limited size handling would help.
